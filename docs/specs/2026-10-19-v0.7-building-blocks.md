# v0.7: building blocks and scale (spec and plan)

- **Roadmap:** `docs/specs/2026-10-19-roadmap.md`, phase "0.8 — Building blocks and scale" (items B1–B6). The roadmap's dynamical-systems phase (D1–D7) was dropped by decision, so this phase becomes 0.7.
- **Depends on:** phase 0.4 (`conn` profile rebase, `SpikeTrains`) and phase 0.6 (`optim` additions).
- **Branch:** `phase/0.7-building-blocks`, stacked on `phase/0.6-fitting`. **PR:** one PR, based on the 0.6 branch.

## Goal

Make `braintools.conn` build large networks quickly and with bounded memory, in the formats brainevent consumes, and make the README's "population networks" claim true. The phase also adds:

- graph analysis of the connectivity that `conn` builds;
- the reservoir and readout learning rules from brainpy 2.x (RLS, LMS, FORCE, ridge, lasso);
- the three common NeuroGym paradigms that `cogtask` still lacks.

## What exists today (facts the plan relies on)

**The connectivity model.**
- `Connectivity(pre_size, post_size, seed)` (`conn/_base.py:234`) produces a `ConnectionResult` (`:44`): COO int64 `pre_indices`/`post_indices`, per-edge `weights`/`delays` (or size 1), positions and `metadata`.
- The exporters are `weight2dense`, `weight2csr`/`delay2csr` (to `brainevent.CSR`), and `delay2matrix`.
- Randomness comes from a legacy `np.random.RandomState(seed)` per instance.

**brainevent 0.2.1** formats:
- `FixedNumPerPre(data, indices, *, shape)`, with `(n_pre, k)` arrays where `W[i, indices[i, k]] = data[i, k]`;
- `FixedNumPerPost` (the same, per post neuron);
- `CSR`/`CSC`.

Indices must be built outside `jit`. There is no COO class, and no JIT fixed-number variant.

**Missing pieces:**
- No class gives a fixed in-degree, fixed out-degree or fixed total number. `FixedProb` is per-pair Bernoulli.
- No population or projection abstraction.

**Hot spots:**
- **Python loops:**
  - `Ring` (`_spatial.py:897`) and `Grid2d` (`:1166`);
  - `RadialPatches` (`:1510`, O(N_pre·n_patches·N_post));
  - `ScaleFree` (`_topological.py:367`, O(N²) time);
  - `Regular` (`:530`);
  - `ModularRandom` (`:731`), `HierarchicalRandom` (`:1348`) and `CorePeripheryRandom` (`:1613`), which are O(N²) Python loops with one scalar draw per pair;
  - the per-post loops in the kernel classes (`_kernel.py:252, 681, 1379`).
- **Dense O(N_pre·N_post) intermediates:**
  - `cdist` plus `rng.random((pre, post))` in `DistanceDependent`/`Gaussian`/`Exponential` (`_spatial.py:254`). This is about 34 B per pair: 3.4 GB at N=1e4, and impossible at 1e5.
  - The same pattern in `ClusteredRandom`, the kernels, and `MorphologyDistance`/`Axonal*`.
  - A dense Bernoulli mask in `Random`/`FixedProb` (`_random.py:176`), `ExcitatoryInhibitory` and the compartment classes.

**brainpy 2.8 `algorithms/`:**
- `RLS(alpha)`, block update `k = P Xᵀ; g = k (I + X P Xᵀ)⁻¹; P ← P − g X P; dw = −g (y − t)`;
- `LMS(alpha)`, `dw = −α Σ_b x_b (y_b − t_b)ᵀ`;
- FORCE, which is RLS on a readout;
- closed-form `RidgeRegression` (`pinv(XᵀX + αI) XᵀY`) and gradient-descent `Lasso`/`ElasticNet`.

**`braintools.optim.Optimizer`** (`_base.py:30`) has only `register_trainable_weights` and `update`. `SOFO` (`_sofo_optimizer.py:172`) is the precedent for a `step(inputs, targets)` signature that doesn't take gradients.

**`cogtask`** already has 14 of the 17 common NeuroGym tasks. Missing: `MultiSensoryIntegration`, `OneTwoThreeGo` and `EconomicDecisionMaking`.

**Benchmarks:** none in the repo.

## Global rules

1. **`conn` stays host-side NumPy.** It is build-time code: roadmap design principle 1 allows host numpy here. Every new or rewritten generator must be:
   - **vectorised:** no Python loop over neurons, pairs or edges; loops over a small fixed number of modules, levels, patches or chunks are fine;
   - **memory-bounded:** no array of size `N_pre × N_post` unless the output itself is that dense (`AllToAll`, `weight2dense`). Work over pre-neuron chunks so that one chunk is at most about `2**22` pairs.
2. **Reproducibility changes are allowed but documented.** Vectorising a generator changes which edges a given `seed` produces. The distribution must stay the same; tests check the statistics (degree mean/variance, distance profile, connection-probability estimates), not exact edges. Each class whose stream changes gets a `.. versionchanged:: 0.7.0` note in its docstring, and the changelog lists them all. `seed` still gives deterministic output within a version.
3. **Same public API.** Constructor signatures and `ConnectionResult` fields of existing classes do not change. A deliberate behaviour change needs a test and a changelog entry.
4. **Repo conventions as in 0.5/0.6:**
   - NumPy docstrings with doctested examples (`.. code-block:: python` plus `>>>`);
   - co-located `foo_test.py`;
   - coverage of at least 90% per new or changed module;
   - reference values: networkx for graphs, sklearn for regressions, NeuroGym semantics for tasks;
   - an explicit seed or key;
   - `brainstate.transform` instead of Python loops for repeated model stepping (AGENTS rule 10).
5. **WSL memory.** Tests use small sizes, so suites run in seconds. Scale checks use `/usr/bin/time -f %M` on a script, one process at a time, with a peak of at most 4 GB.

## B1: fixed-number connectivity and brainevent exporters (`conn`)

New module `conn/_fixed.py`, with tests.

| Class | Semantics |
|---|---|
| `FixedOutDegree(k, *, allow_self_connections=True, with_replacement=False, weight=None, delay=None, seed=None, ...)` | Each pre neuron connects to exactly `k` post neurons, uniformly. `k` may be an int or a fraction in (0, 1] of `post_num`. |
| `FixedInDegree(k, ...)` | Each post neuron receives exactly `k` pre neurons. |
| `FixedTotalNum(n, *, allow_self_connections=True, with_replacement=False, ...)` | Exactly `n` edges, drawn uniformly over all allowed pairs. |

**Sampling.**
- Without replacement, uniform per row, vectorised over rows:
  - Draw `k` candidates per row, find duplicates in each sorted row, and redraw only those until none remain.
  - When `k > post_num/2`, sample the complement instead.
  - Self-connections are excluded by remapping indices (draw from `post_num − 1` and shift), not by rejection.
- `FixedTotalNum` samples `n` distinct flat pair indices. Use rejection with dedup for `n ≪ N_pre·N_post`, and chunked selection otherwise. It never materialises the dense matrix.
- `k > post_num` (or `post_num − 1` without self-connections) and `with_replacement=False` raise `ValueError`.

**Outputs.** Weights and delays go through the existing `init.param` machinery, as in `Random`. `metadata` records `'degree'`/`'n'` and the mode.

**Exporters on `ConnectionResult`** (`conn/_base.py`):
- `to_fixed_num_per_pre(data='weight')` returns `brainevent.FixedNumPerPre`. It requires every pre neuron to have the same number of edges, otherwise it raises `ValueError` with the observed range.
- `to_fixed_num_per_post(...)` returns `brainevent.FixedNumPerPost`, likewise.
- `to_csc()` returns `brainevent.CSC`.
- `to_scipy_csr()` returns a host `scipy.sparse.csr_matrix` (used by `analysis.graph`).
- Homogeneous weights (size 1) stay scalar in the brainevent object.
- Delays have no brainevent equivalent; export them with `delay2csr` as today.

**Tests:**
- exact degrees;
- no duplicate edges without replacement;
- no self-connections when excluded;
- a uniformity χ² test of the targets;
- `k` given as a fraction;
- the error cases above;
- exporter round trips (`todense()` equals `weight2dense()`);
- vmapped matvec through brainevent equals the dense product;
- an O(N·k) memory check at N=1e5, k=100 in the scale script.

## B2: populations and projections (`conn`)

New module `conn/_network.py`, with tests.

- **`Population(size, *, name, positions=None)`**: a named group of neurons. `size` may be an int or a tuple, and `positions` an `(N, d)` array or Quantity.
- **`Projection(pre, post, connectivity, *, name=None)`**: binds a `Connectivity` to two populations, passing their sizes and positions.
- **`Network(populations, projections)`** has two methods:
  - `build()` returns a dict `{projection_name: ConnectionResult}`.
  - `to_csr(data='weight')` returns one block matrix over the concatenated populations as a `brainevent.CSR`, with global indices `offset[pre] + i`. Population offsets are available as `Network.offsets`. Weight units must agree across projections, otherwise it raises.
- **Duplicate names.** Duplicate population names raise. A projection name defaults to `f"{pre.name}->{post.name}"`, and duplicate projection names raise.
- **Example (docstring and tests).** An E/I network:
  - E: 800 neurons; I: 200 neurons;
  - E→E and E→I as `FixedInDegree(80)`;
  - I→E and I→I as `FixedInDegree(20)`.

  The block CSR's per-block degrees are checked.

This makes the README's "population networks" claim true. The README and `docs/index.rst` wording is updated during integration.

## B3: `analysis.graph` (structural graph measures)

New subpackage `analysis/graph/` with `_graph.py` and tests. All functions accept a `ConnectionResult`, a scipy sparse matrix, or a dense array. They work on host scipy.sparse: these are build-time structural measures, documented as host-only, with no jit. Each docstring says whether the graph is treated as directed and weighted.

| Function | Notes |
|---|---|
| `degree_distribution(conn, *, direction='in'|'out'|'total')` | Returns degrees and a histogram. |
| `clustering_coefficient(conn, *, directed=True, average=True)` | Fagiolo's directed clustering, or the undirected version, matching `networkx.clustering`/`average_clustering`. Computed with sparse matrix products, never dense N². |
| `characteristic_path_length(conn, *, directed=True, n_sources=None, seed=None)` | Mean shortest-path length over reachable pairs, through `scipy.sparse.csgraph.shortest_path` on unweighted hops. `n_sources` samples BFS sources for large graphs. Also returns global efficiency. Matches `networkx.average_shortest_path_length` and `global_efficiency` on connected graphs. |
| `modularity(conn, labels, *, directed=True, resolution=1.0)` | Newman modularity of a given partition (the Leicht–Newman form when directed). Matches `networkx.community.modularity`. |
| `motif_counts(conn)` | Counts the 16 directed triad classes (triad census), computed sparsely, plus the reciprocity of 2-node motifs. Matches `networkx.triadic_census` and `reciprocity`. Raises for graphs above a documented size. |
| `spectral_radius(conn, *, weighted=True)` | Largest absolute eigenvalue through `scipy.sparse.linalg.eigs` (ARPACK), with a dense fallback for small graphs. Matches `numpy.linalg.eigvals`. |
| `small_world_index(conn, *, n_random=10, seed=None)` | σ = (C/C_rand)/(L/L_rand) against degree-preserving random graphs (or Erdős–Rényi with the same density, documented). Optional, if time allows. |

**Reference tests:** networkx on random, small-world, scale-free and modular graphs. networkx is installed; add it to the `testing` extra.

## B4: vectorised and memory-bounded `conn` generators, and a scale benchmark

Rewrite these generators under global rules 1–3:

- **`Ring`, `Grid2d`:** index arithmetic. These are deterministic, so the output must stay **identical**, edge order included; existing tests pin this.
- **`RadialPatches`:**
  - patch centres drawn per pre as an `(N_pre, n_patches)` array;
  - candidates within the radius found by chunked distance blocks;
  - dedup by encoded pair id;
  - output sorted by (pre, post).
- **`ScaleFree`:** Barabási–Albert with the repeated-nodes list. This is O(N·m) total, with a Python loop over new nodes doing O(m) work each, which is allowed by rule 1. Or vectorise further if possible.
- **`Regular`:** vectorised per-row sampling, sharing B1's sampler.
- **`ModularRandom`, `HierarchicalRandom`, `CorePeripheryRandom`:** blockwise Bernoulli sampling. For each block, draw the edge count from a binomial, then sample distinct positions as in `FixedTotalNum`. This removes all per-pair Python loops.
- **`Random`/`FixedProb`, `ExcitatoryInhibitory`, the compartment Bernoulli masks:**
  - chunked over pre rows, at most `2**22` pairs per chunk;
  - for small `p`, the binomial-count method above.
- **`DistanceDependent`/`Gaussian`/`Exponential`, `ClusteredRandom`, the kernel classes (`GaussianKernel`, `DoGKernel`/`MexicanHat`, `GaborKernel`, `Conv2dKernel`, `CustomKernel`, `SobelKernel`, `LaplacianKernel`), and `MorphologyDistance`/`AxonalProjection`/`AxonalBranching`/`AxonalArborization`:**
  - distances and probabilities computed in pre-row chunks (shared helper `conn/_chunk.py`);
  - a `max_distance` cutoff, where the class has one, applied before any per-pair array is kept;
  - the kernels' per-post Python loops replaced by vectorised gathers.
- **`AllToAll`** stays dense, because its output is.

**Benchmark.** `benchmarks/conn_build.py`, a script with no pytest dependency, plus `benchmarks/README.md`. It builds and times these networks, and reports wall time, edge count and peak RSS:

| Case | Size | Connectivity | Edges |
|---|---|---|---|
| (a) | N=1e5 | `FixedProb(0.001)` | about 1e7 |
| (b) | N=1e5 | `FixedInDegree(100)`, exported to `FixedNumPerPost` | |
| (c) | 1e5 neurons on a 2-D sheet | `Gaussian` profile with `max_distance` | about 1e7 |
| (d) | 8 000 + 2 000 neurons | E/I `Network` from B2, exported to block CSR | |

- Peak RSS for each case must stay under 4 GB.
- `--quick` runs N=1e4 for smoke tests.
- A test runs `--quick` in a subprocess and checks the output format.
- Results before and after on this machine go in the PR description.

**Tests:**
- the existing conn tests must pass, except exact-edge assertions on generators whose random stream changed; rewrite those as statistical tests, and list each one in the PR;
- new statistical tests for every rewritten generator;
- memory-bound tests that build N=2e4 without error and with `tracemalloc` peaks below a bound.

## B5: online and closed-form learning rules (`optim`)

New modules `optim/_online.py` and `optim/_regression.py`, with tests.

**Online learning rules:**
- `RLS(alpha=1.0, *, forgetting=1.0)` and `LMS(lr=0.1)` are `braintools.optim.Optimizer` subclasses following the `SOFO` precedent:
  - `register_trainable_weights({'readout': weight_state})`; each weight is `(n_in, n_out)`, and `P` is kept per weight in an `OptimState`;
  - `step(inputs, outputs, targets)` takes a batch `(B, n_in)`, `(B, n_out)` and `(B, n_out)`, updates the weights in place, and returns the error;
  - updates are the brainpy 2.x block equations above, with an optional forgetting factor for RLS;
  - jit-able, and usable inside `brainstate.transform.for_loop`.
- `FORCE` is RLS with FORCE defaults, documented with an example. The example trains a chaotic rate network's readout to produce a sine wave, with the rollout in `for_loop`.

**Closed-form regression:**
- `ridge_regression(X, Y, alpha=1.0, *, fit_intercept=True)` (intercept not penalised);
- `lasso_regression(X, Y, alpha, *, max_iter, tol)` (FISTA in `lax.while_loop`);
- `elastic_net_regression(X, Y, alpha, l1_ratio, ...)`;
- `linear_regression(X, Y)` (`lstsq`).

All four are pure, jit-able and differentiable where meaningful. They return a `RegressionResult(coef, intercept)` NamedTuple.

**Tests:**
- RLS with large `P0` converges to the least-squares solution on a linear problem;
- LMS converges for a small learning rate;
- ridge, lasso and elastic net match sklearn (`Ridge`, `Lasso`, `ElasticNet`, with matching objective scaling) to 1e-5;
- jit and vmap;
- the FORCE sine example reaches a test error below a threshold, with a small network, in seconds.

## Edge cases to test

- **Fixed-number classes:**
  - `k=0`, `k=post_num` (complete rows), and `k > available`, which raises;
  - pre ≠ post sizes;
  - multi-dimensional sizes;
  - fractional `k`;
  - homogeneous and heterogeneous weights;
  - Quantity weights and delays;
  - export of a non-uniform result, which raises.
- **`Network`:**
  - a single population with a self-projection;
  - duplicate names;
  - mixed weight units, which raise;
  - an empty projection (zero edges).
- **Graph measures:**
  - an empty graph;
  - isolated nodes;
  - self-loops, which are ignored and documented;
  - a disconnected graph, where the path length is over reachable pairs and efficiency counts unreachable pairs as 0;
  - weighted versus unweighted.
- **Regressions:**
  - more features than samples;
  - `alpha=0` ridge equals least squares;
  - a constant feature with an intercept;
  - multi-output Y.
- **RLS:** batch size 1 versus larger batches give the same result on the same data order.
- **Chunked generators:** a chunk boundary that does not divide N, and N smaller than one chunk.
