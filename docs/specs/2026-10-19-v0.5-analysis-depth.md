# v0.5 — Analysis depth: spec and plan

- **Roadmap:** `docs/specs/2026-10-19-roadmap.md`, phase 0.5 (items A1–A5)
- **Depends on:** phase 0.4 (`braintools.analysis` skeleton, `spike.SpikeTrains`, `_deprecation`)
- **Branch:** `phase/0.5-analysis`, stacked on `phase/0.4-consolidation`
- **PR:** one PR for the whole phase, based on the 0.4 branch

## Goal

`braintools.analysis` becomes a usable toolbox for the measures a computational neuroscientist computes on simulated or recorded activity. These measures cover:

- spike-train statistics, PSTHs, correlograms and spike-train distances;
- spectral and phase analysis of continuous signals;
- population-level analysis;
- resampling and confidence intervals.

All new functions are JAX-native: they run under `jax.jit` and `jax.vmap` with static shapes and accept brainunit Quantities.

## Global rules for this phase

1. **Static shapes.**
   - Anything that determines an output shape is a static Python value; this covers bin sizes, window lengths, lag ranges, `n_bins`, `n_tapers`, `n_folds` and `max_events`.
   - Results with a data-dependent length are returned padded, with a count or mask, in the style of `SpikeTrains`.
   - Docstrings state the shape rule.
2. **Jit and vmap compatibility is tested** for every new function:
   - one `jax.jit` test and one `jax.vmap` test, over trials or neurons;
   - one `jax.grad` test where the function is documented as differentiable.
3. **Units.**
   - Time arguments accept Quantities, or plain numbers in milliseconds for spike-time measures, matching the `brainstate` convention.
   - Continuous-signal functions take a sampling interval `dt`, a Quantity or seconds, as the existing `spectral` functions do.
   - Rates are returned in Hz as plain arrays, and times as Quantities when the input times were Quantities. Units are never stripped silently: a Quantity in gives a Quantity out wherever the result has a dimension.
4. **Spike input.**
   - Event-based measures (ISI family, correlograms, distances, STA, PSTH) take a `SpikeTrains`.
   - The existing functions that take a dense `(T, N)` matrix keep their signatures.
   - Every new spike function's docstring shows how to get a `SpikeTrains` from a dense raster with `SpikeTrains.from_dense`.
5. **NaN, not exceptions, for undefined values under tracing.** A statistic that is undefined for a neuron, such as CV with fewer than 2 ISIs, is `nan` for that neuron, and the docstring says so. Shape and type errors are raised in Python before tracing.
6. **Randomness** takes an explicit `key: jax.Array` (from `jax.random.key`/`PRNGKey`), never the global brainstate RNG.
7. **No Python loops over neurons, pairs, trials or time steps** (AGENTS.md rule 10). Use `vmap`, `scan` and segment sums. Host-side scipy is allowed only to design static coefficients (Butterworth SOS, DPSS tapers) from static parameters before tracing.
8. **Docstrings** are NumPy style with `.. code-block:: python` doctest examples, and say whether the function is jittable, vmappable and differentiable. Each function has a references section where a canonical paper exists.
9. **Tests** are co-located as `foo.py` ↔ `foo_test.py`. Coverage of every new module must be at least 90%. Reference values come from:
   - `scipy.signal` and `scipy.stats`;
   - `sklearn` (PCA, CCA, mutual information, LDA/ridge decoding);
   - `mne` (multitaper, Morlet);
   - `networkx` where it applies;
   - Elephant 1.2.1 and PySpike 0.9.0 (ISI-/SPIKE-distance, CV2, LV, Fano factor, correlograms, STA, Granger, …).

   **Golden values.** Elephant and PySpike are **not** test dependencies. They live in an isolated reference environment, `/tmp/bt/refenv/bin/python`, which has `elephant`, `pyspike`, `neo` and `quantities` on top of the normal environment. Agents run small scripts there to generate expected values and hard-code them in the tests. Each test records, in a comment, the generating library and version and the exact call that produced the value, so it can be regenerated.

   scipy, sklearn and mne are installed in the main environment and are imported in tests with `pytest.importorskip`. Analytic cases (identical trains, a Poisson process for CV ≈ 1, a pure sinusoid) complement them.

## A1 — `analysis.spike`

### A1a: statistics, PSTH, correlograms, STA (new modules)

| Module | Function | Signature and behaviour |
|---|---|---|
| `_isi.py` | `isi(trains)` | Inter-spike intervals as a padded `(N, K-1)` array (Quantity if the times are), with `nan` beyond `counts-1`. |
| | `cv(trains)` | `std(ISI)/mean(ISI)` per neuron `(N,)`, using population std (`ddof=0`). `nan` if there are fewer than 2 ISIs. |
| | `cv2(trains)` | Holt et al. 1996: `mean(2|I_{k+1}-I_k|/(I_{k+1}+I_k))`. `nan` if there are fewer than 2 ISIs. |
| | `lv(trains)` | Shinomoto et al. 2003: `3/(n-1) Σ ((I_k-I_{k+1})/(I_k+I_{k+1}))²` with n ISIs. `nan` if there are fewer than 2 ISIs. |
| | `fano_factor(x, bin_size=None, axis=0)` | If `x` is a `SpikeTrains`, it is binned with `bin_size` and the variance/mean ratio of the counts is computed across bins, per neuron. Otherwise `x` is a count array and the ratio is computed along `axis` (trials). `ddof=0`. `nan` where the mean is 0. |
| `_psth.py` | `psth(trains, events, window, bin_size, *, rate=True)` | Trial-aligned PSTH. `events` has shape `(E,)`. `window = (t_before, t_after)` relative to each event; static. Returns `(rate_or_count (n_bins, N), bin_edges (n_bins+1,))`. Spikes are counted in `[edge_i, edge_{i+1})`. `rate=True` divides by `E * bin_size` and returns Hz. Events may be padded with `+inf` and are ignored if not finite. |
| `_correlogram.py` | `cross_correlogram(a, b, bin_size, max_lag)` | Row-wise pairs: neuron i of `a` against neuron i of `b`; both must have the same N. Histogram of `t_b - t_a` over `[-max_lag, max_lag]` with an odd number of bins centred on lag 0, `n_bins = 2*ceil(max_lag/bin_size)+1`. Returns `(counts (N, n_bins), lags (n_bins,))`. All-pairs use is shown with `SpikeTrains.select` plus vmap in the docstring. |
| | `auto_correlogram(trains, bin_size, max_lag)` | `cross_correlogram(trains, trains)` with the zero-lag self-pairs (`k == k'`) removed. |
| `_sta.py` | `spike_triggered_average(trains, signal, dt, window)` | `signal` has shape `(T, ...)`, sampled at `dt` from `trains.t_start`. `window = (t_before, t_after)` is static. Returns `(sta (N, L, ...), lags (L,))`. Spikes whose window leaves the signal are excluded; a neuron with no usable spike gets `nan`. |

### A1b: spike-train distances and jittable rewrites (`_distance.py`, `_firings.py`)

| Function | Change |
|---|---|
| `isi_distance(a, b, t_start=None, t_stop=None)` | **New** (Kreuz et al. 2007), in `_distance.py`. Exact time average of the piecewise-constant ISI-profile, using PySpike's edge convention: auxiliary spikes at `t_start`/`t_stop`, as in Kreuz et al. 2015. Row-wise over neurons, so it returns `(N,)`. Pair-matrix use goes through vmap, shown in the docstring. |
| `spike_distance(a, b, t_start=None, t_stop=None)` | **New** (Kreuz et al. 2013), with the same conventions. The profile is piecewise linear, so the time average is integrated exactly with the trapezoid rule over the merged spike times. |
| `victor_purpura_distance` | Becomes jittable: the dynamic programme runs as `lax.scan` over rows with an inner `scan` over columns. It accepts 1-D arrays padded with `+inf`, which are treated as absent spikes. It returns a 0-d JAX array instead of a Python `float`; results match the old values exactly in float64 and to `1e-6` relative in float32. |
| `van_rossum_distance` | Becomes jittable: `+inf` padding is masked, and `t_max` must be given under `jit` because the default is data-dependent. It returns a 0-d array. |
| `spike_train_synchrony` | The Python double loop over neuron pairs becomes a vmap over the `(N(N-1)/2,)` upper-triangle pairs, with identical results. It still takes the dense matrix and returns a 0-d array. |
| `burst_synchrony_index`, `spike_time_tiling_coefficient`, `correlation_index` | Python loops over neurons or pairs are replaced in the same way where they exist; results are identical. |

All three return-type changes (Python `float` → 0-d array) are recorded in the changelog under **Changed**. Code doing `float(d)` keeps working.

## A2 — `analysis.spectral` (new module `_spectral.py`; the existing `_lfp.py` is untouched)

| Function | Behaviour | Reference |
|---|---|---|
| `spectrogram(x, dt, nperseg, noverlap=None, window='hann')` | STFT power of `x (T, ...)` along time axis 0. Returns `(freqs (F,), times (S,), Sxx (F, S, ...))`. The reference is scipy with `axis=0`, which returns `(F, ..., S)`, moved into this layout. | `scipy.signal.spectrogram` (`scaling='density'`, `mode='psd'`) |
| `multitaper_psd(x, dt, nw=4.0, n_tapers=None)` | DPSS tapers are designed on the host with `scipy.signal.windows.dpss` (static), FFT in JAX, eigenvalue-weighted (non-adaptive) average. `n_tapers` defaults to `2*nw-1`. | `mne.time_frequency.psd_array_multitaper(adaptive=False, low_bias=False, normalization='full')` |
| `morlet_transform(x, dt, freqs, n_cycles=7.0)` | Complex Morlet wavelet transform by FFT convolution; `freqs` static; returns complex `(n_freqs, T, ...)`. | `mne.time_frequency.tfr_array_morlet(output='complex')` |
| `bandpass(x, dt, band, order=4)` | Zero-phase Butterworth: SOS designed on the host by `scipy.signal.butter(output='sos')`; forward–backward filtering is a `lax.scan` per section, with scipy's `sosfiltfilt` odd padding and `sosfilt_zi` initial conditions. | `scipy.signal.sosfiltfilt` |
| `analytic_signal(x, axis=0)` | FFT Hilbert transform. | `scipy.signal.hilbert` |
| `band_power(x, dt, band, nperseg=None, relative=False)` | Welch PSD integrated over `band` with the trapezoid rule; `relative=True` divides by the total power. | `scipy.signal.welch` + `scipy.integrate.trapezoid` |
| `plv(x, y, dt=None, band=None)` | Phase-locking value between signals, along time axis 0. If `band` is given, the signals are band-passed first. Returns `(...)`. | numpy reference via `scipy.signal.hilbert` |
| `pli(x, y, dt=None, band=None)` | Phase-lag index, Stam et al. 2007. | numpy reference |
| `wpli(x, y, dt=None, band=None)` | Weighted PLI, Vinck et al. 2011. | numpy reference |

`plv` is distinct from `analysis.spike.phase_locking_value`, which is spike–field; both docstrings cross-reference each other in **See Also**.

## A3 — `analysis.population`

### A3a: dimensionality, alignment, decoding (`_dimensionality.py`, `_decoding.py`, `_information.py`)

| Function | Behaviour | Reference |
|---|---|---|
| `pca(x, n_components=None)` | Rows are samples, axis 0 is time. Computed by mean-centred SVD with deterministic signs (as sklearn's `svd_flip`). Returns a `PCAResult(NamedTuple)` with `components (k, D)`, `explained_variance (k,)`, `explained_variance_ratio (k,)`, `mean (D,)` and `projection (T, k)`. | `sklearn.decomposition.PCA` |
| `participation_ratio(x)` | `(Σλ)²/Σλ²` of the covariance eigenvalues. | numpy |
| `cca(x, y, n_components=None, reg=0.0)` | Canonical correlations and weights via SVD of the whitened cross-covariance; `reg` is ridge on the covariances. Returns `CCAResult(correlations, x_weights, y_weights)`. | numpy reference (sklearn CCA is iterative PLS, used only as a loose check on the first correlation) |
| `rdm(x, metric='correlation')` | Representational dissimilarity matrix over conditions (rows of `x`). Metrics: `'correlation'`, `'euclidean'`, `'cosine'`. | `scipy.spatial.distance.pdist` + `squareform` |
| `rsa(rdm_a, rdm_b, method='spearman')` | Correlation of the upper triangles; `'spearman'` ranks with average ties, or `'pearson'`. | `scipy.stats.spearmanr` / `pearsonr` |
| `decode(x, y, n_classes=None, n_folds=5, model='lda', reg=1e-3, key=None)` | Cross-validated linear decoding of integer labels `y`. `model='lda'` uses shrinkage LDA; `model='ridge'` is a one-vs-rest ridge classifier. `n_folds` folds are of equal static size: the trailing `T mod n_folds` samples are dropped, documented. With `key`, samples are permuted before folding. Folds are vmapped. Returns the per-fold accuracy `(n_folds,)`. The number of classes is static: `n_classes=None` means `int(y.max())+1`, which is computed eagerly, and the value must be passed explicitly under jit. | `sklearn` `LinearDiscriminantAnalysis(solver='lsqr', shrinkage=...)` and `RidgeClassifier` on the same folds |
| `mutual_information(x, y, bins=None)` | Plug-in MI in nats between discrete integer arrays. If `bins` is given, continuous inputs are histogram-binned into equal-width static bins first. | `sklearn.metrics.mutual_info_score` |

### A3b: synchrony, causality, criticality (`_dynamics.py`)

| Function | Behaviour |
|---|---|
| `kuramoto_order_parameter(phases, axis=-1)` | Returns `|mean(exp(iθ))|` over oscillators, per time step. With `return_phase=True` it also returns the mean phase. |
| `granger_causality(x, order)` | Pairwise conditional VAR-Granger: for each target i and source j, `log(σ²_restricted/σ²_full)`, where the full model includes all N variables. The restricted model drops source j. Ordinary least squares via `jnp.linalg.lstsq`; `order` is static. Returns `(N, N)` with `GC[i, j] = j → i` and a zero diagonal. Reference: numpy OLS implementation in the test, plus the bivariate AR(1) analytic case. |
| `avalanches(counts, threshold=0, max_avalanches=None)` | Avalanches in a population count series `(T,)`: maximal runs of bins with `counts > threshold`. Returns `AvalancheResult(sizes, durations, n)`, padded to `max_avalanches` (static; default `T//2 + 1`, the maximum possible) with zeros, plus `n`. The size of an avalanche is the sum of `counts - threshold` over the run. |
| `branching_ratio(counts, method='ratio')` | `'ratio'`: mean of `n_{t+1}/n_t` over `t` with `n_t > 0` (Beggs & Plenz 2003). `'regression'`: slope of the linear regression of `n_{t+1}` on `n_t`, which is the conventional MR estimator at lag 1. |

## A4 — `analysis.stats`: resampling (`_resampling.py`)

| Function | Behaviour |
|---|---|
| `jitter_spikes(key, trains, width, method='uniform')` | Each spike is moved by an independent `U(-width, width)` (`'uniform'`) or `N(0, width)` (`'gaussian'`) offset, and the times are re-sorted per neuron. Spikes moved outside `[t_start, t_stop)` are reflected back. `counts` is unchanged. |
| `shuffle_isi(key, trains)` | Permutes each neuron's ISIs and rebuilds times from its first spike, so the ISI distribution and the count are preserved. Implemented with a masked per-row permutation (`jax.random.permutation` on keys from `split`, with the padding kept at the end). |
| `phase_randomize(key, x, axis=0)` | FFT phase randomisation with Hermitian symmetry. It preserves the power spectrum, and keeps DC and Nyquist real. With `same_phases=True`, all channels share one random phase set, which preserves cross-correlations (Prichard & Theiler 1994). |
| `bootstrap_ci(key, data, statistic, n_resamples=1000, confidence=0.95, method='percentile', axis=0)` | `statistic` is traced once and vmapped over the resamples. Methods: `'percentile'` and `'basic'`. Returns `(low, high)`. Reference: `scipy.stats.bootstrap` gives the same interval within Monte-Carlo tolerance for a large `n_resamples`. |

The names avoid "surrogate", to prevent confusion with the `braintools.surrogate` package.

1. The full suite, one process per subpackage, has no new failures compared with the 0.4 branch.
2. Every new function has a jit and a vmap test, plus a grad test where documented as differentiable, and a reference-value test.
3. Coverage of every new module is at least 90% (`coverage run`).
4. mypy is clean on `braintools/analysis` (already in `[tool.mypy] files`).
5. The docs build has no new warnings mentioning `analysis`.
6. Downstream smoke: the brainpy, brainmass and brainpy_state call sites still work. The functions with changed return types, `victor_purpura_distance` and `van_rossum_distance`, are not called downstream; this must be re-verified with grep.

## Edge cases to test

- **Spike counts:**
  - a neuron with 0, 1 or 2 spikes (ISI-family `nan`, correlogram all zeros);
  - all neurons silent;
  - capacity `K = 1`.
- **Timing:**
  - spikes exactly on bin edges and window bounds (half-open convention);
  - spikes at `t_start`/`t_stop` for the ISI- and SPIKE-distances;
  - identical trains (distance 0);
  - one empty train (distance per the PySpike convention).
- **PSTH:** events whose window extends outside the recording, and padded `+inf` events.
- **STA:** spikes near the start of the signal, which are excluded.
- **Spectral:**
  - a signal shorter than `nperseg` (raise eagerly);
  - a band edge at or above Nyquist (raise);
  - odd and even lengths for `analytic_signal` and `phase_randomize` (the Nyquist bin).
- **Decoding:** `T` not divisible by `n_folds`; a class absent from a training fold.
- **Avalanches:** a series that starts or ends inside an avalanche; an all-zero series (`n = 0`); no quiet bins at all.
- **Granger:** perfectly collinear inputs, handled by lstsq without NaN.
- **Units:** Quantity versus plain number inputs give the same magnitudes.
- **Precision:** results in float32 and float64.
